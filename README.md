# Speedy Hedgehog

A small Expo / React Native starter game with ring collection, jumping, an enemy, a three-hit boss, hearts, and restart.

## Run locally
1. Install Node.js and the Expo/EAS tools on a computer.
2. Run `npm install`.
3. Run `npx expo start`.

## Build an Android APK with EAS
1. Sign in to Expo.
2. Install EAS CLI: `npm install -g eas-cli`.
3. Run `eas build:configure`.
4. Run `eas build --platform android --profile preview`.

The `preview` profile is configured to create an installable APK. A parent or guardian should help with account setup and publishing/build steps.

## Artwork
This starter uses emoji and simple shapes as placeholders. It is an unofficial fan-made project and does not include official Sonic/SEGA artwork or assets.
